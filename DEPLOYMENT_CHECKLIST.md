# ✅ Diaspora Platform - Deployment Checklist

Use this checklist to ensure everything is properly configured before and after deployment.

---

## 📋 Pre-Deployment Checklist

### Environment & Dependencies
- [ ] Node.js v20+ installed
- [ ] pnpm v9.15.9 installed
- [ ] Git installed and configured
- [ ] All dependencies installed (`pnpm install`)
- [ ] No TypeScript errors (`pnpm lint`)

### GitHub Setup
- [ ] GitHub account created
- [ ] Repository created (no README/.gitignore/license)
- [ ] Code pushed to main branch
- [ ] `.gitignore` is properly configured

### Railway Setup
- [ ] Railway account created
- [ ] Project initialized
- [ ] PostgreSQL database provisioned
- [ ] Environment variables configured:
  - [ ] `JWT_SECRET` (64+ characters)
  - [ ] `SESSION_SECRET` (64+ characters)
  - [ ] `FRONTEND_URL` (Vercel URL)
  - [ ] `NODE_ENV=production`
  - [ ] `DATABASE_URL` (auto-set by Railway)
- [ ] Database schema pushed (`railway run pnpm db:push`)
- [ ] Data seeded (`railway run pnpm db:seed`)
- [ ] Deployment successful

### Vercel Setup
- [ ] Vercel account created
- [ ] Project linked
- [ ] Environment variables configured:
  - [ ] `NEXT_PUBLIC_API_URL` (Railway URL)
  - [ ] `NEXT_PUBLIC_APP_URL` (Vercel URL)
  - [ ] `NEXT_PUBLIC_SENTRY_DSN` (optional)
- [ ] Production deployment successful

---

## 🔐 Security Checklist

### Authentication & Secrets
- [ ] JWT secret is random and 64+ characters
- [ ] Session secret is random and 64+ characters
- [ ] Database password is strong (auto-generated by Railway)
- [ ] No secrets committed to Git
- [ ] `.env` file in `.gitignore`

### API Security
- [ ] CORS configured for production domain
- [ ] Rate limiting enabled
- [ ] Helmet security headers active
- [ ] CSRF protection enabled
- [ ] HTTPS enforced (automatic on Vercel/Railway)

### Database Security
- [ ] Database not publicly accessible
- [ ] Connection string uses SSL (Railway default)
- [ ] Prisma generated for production

### Health & Status
- [ ] Health check returns 200: `GET /health`

- [ ] Version displayed correctly

### Frontend Testing
- [ ] Homepage loads without errors
- [ ] All images and assets load
- [ ] Navigation works
- [ ] Mobile responsive
- [ ] Dark mode toggle works

### Authentication Testing
- [ ] Login works with test credentials
- [ ] Registration creates new user
- [ ] Email verification flow works (if email configured)
- [ ] Password reset flow works (if email configured)
- [ ] Protected routes redirect to login
- [ ] Logout clears session

### API Testing
```bash
# Test login endpoint
curl -X POST https://your-railway-url/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"admin@diaspora.com","password":"admin123"}'

# Test protected endpoint
curl https://your-railway-url/auth/me \
  -H "Authorization: Bearer YOUR_TOKEN"

# Test health endpoint
curl https://your-railway-url/health
```

- [ ] Login returns valid JWT token
- [ ] Protected endpoints require authentication
- [ ] Admin endpoints require admin role
- [ ] Rate limiting works (test with multiple requests)
